**Reuse:** the Crustdata client (cache, replay, ledger, resume) covers company enrich and person enrich only if the endpoint works. The approval gate and idempotent executor are designed but not built. The rules table, application filler and insurer shortlist are all new work.

**Data risk (high):**
- job/search returned HTTP 400 at 14:00 and the request shape is unfixed. The 113-of-3,362 count has no recorded response, so it cannot be a fixture.
- Person enrich and the person watcher have no recorded response. The cover-gap alarm, the headline feature, rests on the watcher.
- The insurer shortlist needs regulator figures via web fetch, whose cost is unmeasured and whose output is unparsed. The cover-gap rules table is unwritten.
- No duplicate or lookalike case exists. Company search for "similar employers" is unverified.

**Demo risk (high):** there is no script. A live person watch needs a real opted-in profile with a job change dated after 1 Sep 2026, and nobody has one. Buying an insurance policy is irreversible and the idempotency design is missing. A licence and ethics debate would eat the 2-minute demo.

**Cut-lines if forced:** (1) employer benchmark from job search plus fact file with Told/Checked/Guessed labels, (2) cover-gap computed from a small hard-coded table, (3) prepared-not-sent request behind approval. Drop insurer ranking, the claims helper, the driver scheme matcher and shipment cover.

**Cheapest live check (about 3 credits):** fix the job/search body from the docs and run one query (logistics, India, since 1 Sep 2026, "health insurance"), recording the response. Then run one person enrich (1 credit) on a known profile with a job change, and one free watcher /test. If job search fails again, the idea is dead.

**Top 3 of the ideas given:** only one idea was reviewed, so no ranking is possible. This would be a fallback component at best.

**Fatal flaws:**
- The headline value (the alarm) depends on an unverified watcher.
- The "client" is the employer, but the value is brokerage advice, so the customer is unclear.
- Scope is about three ideas in one.

**Recommended merges:** take only the Told/Checked/Guessed fact file and the job-change rule into a stronger E2E idea (e.g. As-Of or FactGate). Do not ship as a standalone.

**Score: 2/5**
