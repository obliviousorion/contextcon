# Idea pool (12 ideas from 4 ideation agents; rupee figures are UNSOURCED agent estimates)
Common facts: Crustdata records are stored copies with a refresh date; headcount time series starts late Nov 2022 and is a lower bound (misses drivers/warehouse staff); person first/last name fields come back empty; job-search coverage for Indian blue-collar roles unverified; MCP tool names unverified; costs: person record 1 credit, company record 2, company identify 0.2/match, web search 1, watch alert 5.

## Family A: counterparty monitoring (carriers/suppliers/customers)
1. Carrier Pulse (client-first): monthly carrier/supplier distress watchlist, RAG status per carrier from headcount.timeseries + job/search freeze + web news (insolvency/NCLT) + watch. Est. buyer value Rs 15-60k/counterparty/yr. Tests: -25% headcount => AMBER; lookalike "Express" carriers resolved by domain else cannot verify; insolvency rumour with no fetched page => cannot verify. Risk: headcount is a lower bound.
2. LaneWatch (surface): same family. Dated Hold/Continue verdict "is carrier operationally healthy as of date X"; headcount slope + job-posting freeze + senior departures (person/search) + news + watcher trigger with free /test. Est. Rs 15-30k per carrier report or Rs 40-80k/month retainer. Risk: sparse series => many cannot verify.
3. Account Watch (client-first): watch the 3PL's own shipper-customers for churn/expansion signals (hiring supply-chain roles, funding, layoffs) via watchers+webhooks. Est. Rs 5-20 lakh/yr. Risk: correlational; surveillance optics.

## Family B: market/bid intelligence
4. Bid Intel (client-first): pre-tender dossier on 3-5 named rivals (new hubs/offices, hiring by city, funding, leadership changes last 90 days) from company enrich + job/search + web fetch + person search. Est. Rs 2-8 lakh/report. Tests include "is rival X bidding for tender Y?" => cannot verify. Risk: stale data vs a "last 30 days" test.
5. Expansion Site Scout (surface): city x employer matrix of customer job postings as warehouse-location demand proxy + local ops-talent counts. Est. Rs 2-5 lakh/brief. Risk: job-search coverage for Indian blue-collar roles unverified.
6. Same Hands (contrarian): tender collusion / related-party graph: bidders sharing domains, office addresses, directors (company/enrich all_domains/all_office_addresses, person/enrich); outputs shared attributes only, never "collusion". Est. Rs 15-30k/tender audit. Risk: defamation/ethics exposure.

## Family C: verification-as-a-service of OTHER parties' facts/outputs (tool layer / MCP)
7. FactGate (MCP/infra): an MCP server any agent calls: verify_fact(subject, field, as_of) returns only {value, exact_passage, url, record_date, cost} or CANNOT_VERIFY{missing}; recheck(fact_id); clear_vendor job (~Rs 600/dossier vs Rs 1,500-4,000 KYB). SQLite ledger, idempotency keys, approvals table. Second client = tenant key. Covers Trust&Compliance + Infrastructure-for-agents tracks. Risk: stored copies often predate question => many cannot verify; MCP tool names unverified.
8. BudgetBroker (MCP/infra): MCP proxy in front of Crustdata: quote -> reserve -> commit priced purchase orders, live cap file client can cut mid-run, cheapest-endpoint choice, partial results naming what was skipped (~Rs 250/job). Risk: judges may see it as plumbing.
9. ProvenanceAudit (MCP/infra): takes another agent's memo, splits into atomic claims, grades sourced / memory-only / unverifiable, re-fetches via web/fetch + company/enrich, approve/hold/block per claim (~Rs 300/memo vs few thousand). Risk: noisy claim-splitting; bias to hold.
10. Second Opinion (contrarian): re-verifies every line of ANOTHER firm's carrier-compliance pack: agree/contradict/cannot verify, catches lookalike mix-ups and stale pages (~Rs 1,500-2,500/pack). Risk: close to vendor-check.

## Family D: temporal
11. As-Of (contrarian): dated diligence affidavit: for a carrier and date D (after a cargo loss/SLA dispute), what can records PROVE about the carrier as of D (existence, size via nearest headcount point on/before D, registered name/domain); refuses when record refreshed after D or D before Nov 2022 ("cannot attest"). Est. Rs 3,000-6,000/file vs disputed claims Rs 2-20 lakh. Risk: sparse series => mostly cannot verify; thin-looking demo.
12. Notice-Period Counterparty Alert (surface): watchlist of named contacts/signatories at carriers/customers; person-change watcher triggers re-verification (Rs 500-1,500/contact). Uses is_default, crustdata_company_id, redacted rules. Risk: thin; person-watch path unverified.


## Added from the 5th agent (rubric maximizer)
13. Receivables Sentinel: the 3PL CFO/credit-control head's customer credit-distress watch. Headcount decline + hiring freeze + layoff news as leading indicators of non-payment; output "hold / watch / extend credit" (never a default prediction, "risk indicator, not a finding"). company/identify + company/enrich (headcount.timeseries, by_role_absolute, revenue) + job/search + watch webhooks (free /test) + web search/fetch for exact passages. Est. Rs 1,500-5,000 per customer review or Rs 50k-1.5L/month per 100-shipper book vs credit-bureau reports and bad-debt loss. Tests: 30% headcount drop in 90 days => tighten credit with dated field; group firm vs subsidiary kept separate; "will X default?" => cannot verify naming the missing court/insolvency record. Approval gates: cutting credit limit, pausing dispatch, dunning email. Rules in YAML => easy live fix; second client = tenant config. Risk: proxy signal, headcount lower bound.
14. Master-Data Golden Record desk: dedupe/entity-resolution for the 3PL's customer and carrier master data; explicit merge / no-merge / cannot_verify verdict per pair, never silently merged. company/identify (name+domain), company/search + autocomplete, company/enrich (all_domains, year_founded, all_office_addresses), web/fetch tie-break. Est. Rs 5-20 per record or Rs 50k-2L per 10,000-row clean-up. Tests: same-domain name variants => merge; same name different city/founding year => no merge with reason; bare name no domain => cannot_verify. Merges/deletes in client master are irreversible => approval + idempotent on pair-hash. Risk: may read as "vendor check by another name"; thin personal-data story.
15. Tender Conflict-of-Interest Desk: screens bidders' directors/key people against the client's evaluators/employer history (person/search + person/enrich experience.employment_details, company/identify, web search); outputs "disclosure to clarify", never an accusation; held "please clarify" email only. Est. Rs 1-3 lakh per tender review. Tests: director overlapped at client 14 months => clarify with dated records; namesake cleared; first-of-month date ambiguity or no staff counts => cannot_verify. Most personal-data-heavy idea; overlaps Trust&Compliance (and idea 6).
